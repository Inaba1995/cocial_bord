# Cocial Bord

Социальная сеть на Django с возможностью создания постов, лайков, комментариев и подписок.

## Возможности

- Регистрация и авторизация пользователей
- Создание, редактирование и удаление постов
- Загрузка изображений к постам
- Лайки через AJAX (без перезагрузки страницы)
- Комментарии с AJAX-отправкой
- Подписка/отписка на пользователей
- Поиск по постам и пользователям
- Пагинация ленты
- Адаптивный дизайн (Bootstrap 5)

## Стек

- Python, Django 6.0
- SQLite
- HTML, CSS, Bootstrap 5
- JavaScript (AJAX)
- Pillow

## Установка и запуск

1. Клонируйте репозиторий
2. Установите зависимости:
```bash
pip install -r SocialBord/requirements.txt
```
3. Примените миграции:
```bash
cd SocialBord && python manage.py migrate
```
4. Запустите сервер:
```bash
python manage.py runserver
```
