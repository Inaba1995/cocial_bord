# Cocial Bord

Социальная сеть на Django с лентой постов, лайками, комментариями и подписками.

## Цель проекта
Разработать полноценную социальную сеть с базовым функционалом: регистрация, создание контента, взаимодействие между пользователями.

## Задачи
- Реализовать регистрацию и авторизацию пользователей
- Создать ленту постов с пагинацией
- Добавить возможность ставить лайки через AJAX
- Реализовать комментарии с отправкой без перезагрузки
- Добавить подписки на пользователей
- Реализовать поиск по постам и пользователям

## Результат
Работающее веб-приложение с адаптивным дизайном, лентой постов, системой лайков/комментариев и подписок.

## Стек технологий
- Python, Django 6.0
- SQLite
- HTML, CSS, Bootstrap 5
- JavaScript (AJAX)
- Pillow

## Установка и запуск
```bash
pip install -r SocialBord/requirements.txt
cd SocialBord && python manage.py migrate
python manage.py runserver
```
